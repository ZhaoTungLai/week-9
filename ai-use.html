AI use declaration

What the assistant did, what remains a human responsibility, and where the process needed correction.

01

Tools and model

I used Codex, an OpenAI coding assistant, in the Codex desktop app. I also consulted the public NV Atlas site and the OpenSubtitles corpus attribution documented there. The assistant did not have direct access to the private submission account or course portal.

02

What AI was asked to do

AI was asked to read the project brief, identify the requirements, inspect the existing CSV, retrieve the public NV Atlas index, implement a reproducible sample builder, design and code the static site, draft bilingual interface text, draft the learning report and codebook, and run structural checks on the result.

03

What I did and checked

I supplied the project brief and the existing CSV, selected the translation topic and source direction, and reviewed the resulting site. The required human spot check is still outstanding: all 500 entries remain marked human_checked = no until a person compares the 50-row verification sample with the source records. Human checking cannot be delegated to the assistant.

04

Prompts that worked

“Read the attached project brief and inspect the existing corpus. Build a static GitHub Pages explorer with a reproducible sampling method, linked visualizations, URL state, a bilingual interface, and a learning report.”
“Show which required fields are missing and distinguish machine-matched rows from rows that a human has actually verified. Do not claim human verification we have not done.”

05

Where AI went wrong

The first draft treated the existing 500-row CSV as if it already met the brief. It did not: the CSV lacked the required source, category, and human-check fields, and it was a sequential set rather than a documented random sample. The assistant also initially over-classified terms such as dance through a suffix rule. Both problems were caught by comparing the draft against the brief and by inspecting the category examples; the sample builder and taxonomy were revised accordingly.

06

Limits

AI could draft code and prose quickly, but it could not decide the final category for every ambiguous entry, verify 50 rows by eye, establish copyright permission beyond the source’s stated attribution, or guarantee that the public index is representative of all subtitles. Those remain human and source-level decisions.
